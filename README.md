# Siro's Skills

个人 OpenCode 技能集合仓库。每个技能是一个独立目录，包含 `SKILL.md` 与可选的 `evals/` 测试用例。

## 技能列表

| 技能 | 说明 | 触发场景 |
| --- | --- | --- |
| [wudu-novel-writing](./wudu-novel-writing/) | 二次元轻小说正文写作（雾都文风蒸馏版） | 写小说正文、续写章节、模仿文风、把大纲扩写为正文 |
| [wudu-text-review](./wudu-text-review/) | 正文校验与修改（雾都文风蒸馏版） | 校验/审稿/文风体检、挑毛病、检查并修改、对齐文风、打分 |
| [wudu-outline-craft](./wudu-outline-craft/) | 大纲与小剧情编排（雾都结构蒸馏版） | 写大纲、章节规划、编排剧情、单章内小剧情、分镜规划、场景序列 |

### wudu-novel-writing

从 21 万字符中文小说样本（转生史莱姆同人·二次元轻小说文风）中蒸馏出的完整写作技能。

- **文气指纹**：短段分镜 × 吐槽旁白 × 二次元设定不解释 × 反差萌 × 甜宠微动作 × 月光意象
- **内置**：文风快照卡片、符号/语气词系统、五种场景标准动作（战斗三拍法/对话三件套/日常锚点/心理三句式/景物两笔勾景）、叙事纪律（视角/节奏/信息投放/情绪渲染）、错别字勘误清单、快速/标准/精修三档输出模式
- **测试**：`evals/evals.json` 含 3 个用例（续写/战斗/改写），实测带技能 100% 通过率 vs 基线 61%

### wudu-text-review

从同一份 21 万字符样本中蒸馏出的「正文校验与修改」技能，与 wudu-novel-writing 文气基准同源。

- **检测**：10 维扫描（符号系统/语气词口癖/单句段比例/长句/明喻/微动作/心理轻量/景物/设定不解释/吐槽旁白）+ 错别字勘误清单 + 黑名单词，严重度分级（S1-S4）带证据定位
- **修订**：九类手法（拆长段三拍法/引号归位/心理外化/补语气词/以画面换词等），最小干预原则，保留作者原意与个性表达
- **报告**：五维加权评分（语气25%+勘误25%+句式20%+符号15%+叙事15%），快速扫描/标准/深度精修三档模式
- **配套**：`references/validation-sample.md` 含五类场景黄金参照段与量化基线（每千字密度）
- **测试**：`evals/evals.json` 含 2 个用例（校验修改/纯校验），实测带技能 100% 通过率 vs 基线 54%

### wudu-outline-craft

从同一份 21 万字符样本中蒸馏出的「大纲与小剧情编排」技能，与写作/校验技能构成完整流水线（大纲→正文→校验）。

- **结构指纹**：多线并置 × 硬切推进 × 弱线短/强线长/高潮压轴 × 张弛交替 × 伏笔埋日常收高潮
- **内置**：卷纲/章纲/分镜表模板（含爆点句字段）、章内七拍节拍模型、四型章节配方（战斗/日常/过渡/转折）、小剧情单元四要素（目标/冲突/转折/落点）、钩子四类型与埋点法、多线并置表、伏笔登记表（埋/推/收三态）、情绪曲线、字数分配表、三档模式
- **接口**：分镜表字段与 wudu-novel-writing 硬兼容，产出可直接交接执行
- **测试**：`evals/evals.json` 含 3 个用例（章大纲/章内节拍/卷大纲），实测带技能 100% 通过率 vs 基线 78%（差距集中在卷级规范字段与字段级可执行性）

## 安装

### 全局安装（所有项目可用，推荐）

将技能目录复制到 OpenCode 全局技能目录：

```powershell
Copy-Item -Recurse .\wudu-novel-writing "$env:USERPROFILE\.config\opencode\skills\"
```

### 项目级安装（仅当前项目可用）

```powershell
Copy-Item -Recurse .\wudu-novel-writing ".\opencode\skills\"
```

目录名必须与 `SKILL.md` frontmatter 中的 `name` 一致。

## 目录结构

```
skills/
├── .gitignore              # 排除样本素材/测试工作区/临时文件
├── README.md
└── <skill-name>/
    ├── SKILL.md            # 技能主体（frontmatter + 指令）
    └── evals/
        └── evals.json      # 测试用例（可选）
```

## 开发约定

- `SKILL.md` 的 `description` 承担技能触发职责：写明"何时触发/做什么"，并包含触发词
- 版权/私有样本（`.docx`、`.txt` 等）不入库，由 `.gitignore` 排除
- 测试工作区（`*-workspace/`、`iteration-*/`）不入库
