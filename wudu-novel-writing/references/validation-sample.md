# 校验样本（Validation Sample）——雾都文风对齐基准

> 从《样本_去除PS.docx》（196,837字 / 7,011段）蒸馏出的**文气对齐基准**。
> 用途：对已有正文做对齐与校验——逐项核对是否贴合样本文气，输出校验报告。
> 使用方式：校验时打开本文件，先过"四、量化基线"，再用"一、黄金参照段"比对语感，最后按"五、校验流程"输出报告。

---

## 一、黄金参照段（五类场景原文摘录，语感垫底用）

校验正文前，先默读对应场景的黄金段，让语感对齐，再逐项核对。

### 1.1 战斗——爆发切镜（能量意象×宏大喻体×短句定格）

```
『对不起』
蓝紫光束，贯穿天空。
恍若审判的长矛，轻而易举撕碎一片荒芜的大地。
光束直击处，巨大的圆柱形坑洞深不见底，狰狞的裂纹在周围散开。
片刻后，磅礴的能量猛地自地底爆发。
半球形冲击波席卷了整个国王谷，所以触碰到的物体，皆崩解为粉尘。
当所以动荡都过去之后，先前还算是有些生气的国王谷，变成了一片死地。
```

校验要点：一句一镜、动词驱动、能量意象先行、宏大喻体（审判的长矛）、余波定格（死地）。

### 1.2 对话交锋——潜台词×抢话×微动作伴随

```
「那我就开门见山地问了——您，有着另外的打算吧？」
露姆停下空间折跃，绕有兴致的望着对方红黑的眼瞳。
黑银异瞳稍稍眯起，在一成不变的微笑之上，嘴角扬起的弧度似乎更大了一点。
那神情，仿佛发现了感兴趣的东西一样。
「不错，我不打算一直跟着利姆露想法来走，虽然最终为了他这一点永远不会变，但我想用一些更加好的方法，一直在破破烂烂的计划上打补丁实在让人提不起干劲」
沉默片刻，露姆仿佛不打算隐藏，说了不少东西。
迪亚波罗始终在思考，直到他做好决定——
「那么，到时候就让我追随您吧」
「你可是远在法尔姆斯呐……嘛，到时候我也会去一趟就是了」
露姆只是笑了笑，随口一说。
「你是绝对忠诚于利姆露的不是吗？那么……」
「我将永远响应您的召唤」
说完，迪亚波罗就消失了。
```

校验要点：一言一段、一来一回、每句台词配微动作、潜台词靠省略号与试探推进、语气词（呐/嘛）嵌在对话里。

### 1.3 心理——『』直引×三句式×点到即止

```
『没有紫克众、飞龙众的人数也不足三位数，果然，是因为蝴蝶效应吗？』
远处旁观的露姆，仔细清点一遍军队组成，发现了与记忆的不匹配之处。
——紫苑一直都活的好好的，所以自然也就没有获得什么不死性。
——蜥蜴人部落被猪头人血洗，收留下来的也不过是运气好逃出来的年轻一辈，人数有数百是肯定不可能的事。
或许军队战斗力也有变化，不过最明显的不同，就只有这两点。
『如果是这样，所谓蝴蝶效应未免也太微弱了』
自己介入了那么多事，到现在只不过这一点不一样，让人有点怀疑蝴蝶效应的存在性。
『倒也是好事……』
```

校验要点：『』直接引述（≤3句）、判断句收束、破折号补充段（1-3句为限）、无长篇分析。

### 1.4 景物——两笔勾景×服务情绪×落回人物

```
夜晚的森林，犹如深渊般幽邃危险，尤其是在这新月之夜，茂密的树木之间，黑暗仿佛更加纯粹了。
月依旧如此明亮，只不过那发光的地方，只有寥寥一个月牙罢了。
与之形成鲜明对比的，便是方才建成未有三年时间的魔物之都——魔国联邦「鸠拉·特恩佩斯特」。
街道两旁，无数路灯蜿蜒向远方，宛如连接天与地的光之华柱。
若非是夜晚漆黑的天色，身处其中，又怎会知道外界还尚是夜晚。
```

校验要点：景物≤3行、喻体明喻（深渊/光之华柱）、破折号补充设定、以人物心境收束。

### 1.5 日常——锚点×语气词×微动作×反差点缀

```
甜点心会使人的心情变好，美味的甜点心会使人的心情值翻倍。
——露姆发自内心认为，说出这话的人一定是个天才。
露姆坐在木板登上，小手捏着银色的叉子，轻轻叉起一小块蛋糕，然后将其一口吃下。
幸福的笑容洋溢在可爱的脸蛋上。
那对因为身高而无法触碰到地面的纤细小腿，也在一前一后地摆动着。
「哼哼哼♪~」
「夫人的手艺真是日益精进呐！比起上一次，简直不可同日而语诺！」
对于她的话，在场的人都表示高度赞同。
「口感很棒欸，松松软软的」
「一口下去全是满足」
「对啊对啊，甜度掐得相当精确喵」
```

校验要点：食物/物件做锚点、反差点缀（强大者做幼稚举动）、语气词密度最高处、微动作细节（叉蛋糕/晃小腿）。

## 四、对齐校验流程（对已有正文执行）

1. **定场景**：判定校验对象的主场景类型（战斗/对话/心理/景物/日常/混合），打开对应黄金参照段（第一节）默读一遍。
2. **量化扫描**（可脚本统计）：统计单句段占比、平均段长、语气词密度、符号使用（「」『』——…………～）、黑名单/凑字副词密度，对照第二节阈值表逐项判定。
3. **文气比对**：将正文与黄金参照段逐条比对五类校验要点（分镜/对话/心理/景物/日常），每条记"贴合/偏离"。
4. **勘误扫描**：对照第三节勘误表+全文"的地得"扫描。
5. **输出校验报告**（格式见下）：

```markdown
## 校验报告
- 校验对象：<段落/章节名>｜主场景：<战斗/对话/…>｜字数：xxx字
### 量化指标
| 指标 | 目标 | 实测 | 判定 |
| --- | --- | --- | --- |
| 单句段占比 | ≥60% | xx% | ✅/⚠️/❌ |
| 语气词密度 | 对话≥6/千字 | xx | ✅/❌ |
| 符号分工 | 「」「『』」不混用 | — | ✅/❌ |
| 违禁词 | ≤0.5/千字 | xx | ✅/❌ |
### 文气比对
- 分镜节奏：✅ 贴合（一句一镜）/ ❌ 偏离（说明）
- 对话工艺：…
- 心理处理：…
- 情绪外化：…
### 勘误
- ❌「所以」→「所有」（第x段）
### 结论
- 总体判定：✅ 对齐 / ⚠️ 基本对齐（列出必须修订项） / ❌ 偏离（列出重写建议）
```

## 五、校验判定口径

- **✅ 对齐**：量化指标全部达标，文气比对无偏离，无勘误。
- **⚠️ 基本对齐**：量化达标但文气比对有1-2处可修正偏离，或存在勘误——列出修订项，修订后复检。
- **❌ 偏离**：单句段占比<40%，或语气词密度为0，或符号混用（「」『』不分），或违禁词超标——判定为文风漂移，需按主SKILL.md重写相关段落。

> 判定原则：量化指标是硬门槛，文气比对是软校验。量化不达标必改；文气偏离给修订建议而非全盘否定（避免过度纠正造成模板化）。
