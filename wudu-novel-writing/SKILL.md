# 二次元轻小说正文写作（雾都文风蒸馏版）

## 〇、一句话文气指纹

> **短段分镜 × 吐槽旁白 × 二次元设定不解释 × 反差萌 × 甜宠微动作 × 月光意象**

现代白话×日系轻小说/动漫同人×半口语吐槽风。作者人格不隐身、随时跳出来说话；设定默认读者懂、不写说明书；情绪靠小动作与意象外化、不靠长篇心理分析。

---

## 一、铁律（先于一切）

1. 先接单，后动笔：信息不足时先补齐"接单卡"再开写。
2. 动笔前默诵一遍"文风快照卡片"（第二节）。
3. 任何产出前必须过一遍"错别字勘误"（第八节）。
4. 交付必须附字数统计。
5. 默认标准模式；用户催更/要快用快速模式；要求"仔细/精修/检查"用精修模式。

## 二、文风快照卡片（10条硬规则）

1. **段落极短**：单句段、半句段为骨（"蓝紫光束，贯穿天空。"），单句段占比≥40%；长句只做氛围铺陈；禁止连续3段以上超4行的长段落。
2. **符号系统**：「」对话与专名；『』内心独白与系统宣告；——插入说明/旁白打断；…………（全角省略号×4，独占一行）场景硬切；（）作者吐槽旁注；～亲昵拖音。
3. **语气词系统**（最标志性指纹）：呐（最高频）、嘛、欸、哦、哟、呢、吧、啦、喏；对话/内心/旁白三处都要有密度；同一个人物口癖必须固定。
4. **吐槽役旁白**：作者不隐身——括号插入吐槽、破折号补充设定、旁白自问自答（"至于为什么……自然是有着其特别的用意"）。
5. **设定不解释**：专名/术语用「」包裹直接使用（魔素、术式、究极技能），默认读者懂；设定靠行动与对话渗透，禁止说明书。
6. **反差萌主角**：强大到离谱+娇小可爱并存——用"小手""小脑袋""娇小的身躯"做小动作，同时微笑着做恐怖的事。
7. **甜宠微动作**：摸头、蹭掌心、提裙礼、喂食、十指相扣；动词要细（捏住裙摆、轻轻提起）；点到即止，不煽情。
8. **心理轻量**：思考优先、『』直接引述（≤3句），辅以小动作外化；禁止大段书面心理分析。
9. **景物服务情绪**：月/光/星空/风是情绪道具，两笔带过，只做定场、转场与缓冲。
10. **明喻体系**：仿佛/宛如/犹如/好像/好似；喻体宏大与生活化混杂（"恍若审判的长矛" vs "像巨人在玩跳绳"）。

## 三、符号与语气词精确规则

### 3.1 符号系统

| 符号 | 用途 | 样本实例 |
|---|---|---|
| `「」` | ① 人物台词（所有对话必须用）；② 专有名词/称号/技能名/术语 | 「月辉皇」「阿卡斯缇娅制约阵」 |
| `『』` | ① 内心独白；② 精神世界/思念通话对话；③ 系统/无机质宣告 | 『等着我，利姆露！』 |
| `——` | 插入说明/旁白打断/补充解释（最高频标点，每场景2-4次） | ——傀儡国「吉斯塔夫」 |
| `…………` | 场景硬切分隔符（4个以上全角省略号独占一行） | ………… |
| `……` | 句尾留白、迟疑、潜台词、余韵 | 「这是……黑魂玉！」 |
| `～` | 亲昵语气拖长（对话尾或昵称后，旁白叙述中禁用） | 「维鲁达先生～」 |
| `（……）` | 括号吐槽旁注：作者随时跳出来 | （真的没看见看官们可以细品一下） |

**硬规则：**
1. 「」与『』分工是硬性的：嘴说出来用「」，心里想/系统通告用『』，不可混用。
2. 术语/称号/技能名出现即用「」包裹且不解释。
3. 场景切换用…………硬切，禁止"与此同时""镜头一转""让我们把目光移向"等书面过渡。
4. ～只用在对话尾部或昵称后。

### 3.2 语气词系统

| 语气词 | 用法 | 样本 |
|---|---|---|
| 呐（最高频） | 句尾感叹/提醒/亲密嗔怪 | 「真是烦恼呐～」 |
| 嘛 | 句首缓和、敷衍、让步 | 「嘛，也算不上什么精英教育」 |
| 欸 | 惊讶/反问 | 「欸？不会怪我吗？」 |
| 哟/哦～ | 句尾强调，常带拖音 | 「找到你了哦～」 |
| 啦 | 撒娇/不满/反驳 | 「都说了不是啦」 |
| 喏/诺 | 略带俏皮的句尾 | 「真是可惜喏～」 |
| 呢 | 反问/疑问收束 | 「干嘛要浪费这么多时间呐！」 |
| 的说 | 陈述句尾撒娇 | 「咱会很困扰的说……」 |
| 喵/嘶等 | 种族口癖（固定人设锚点） | 「甜度掐得相当精确喵」 |

**规则：**
1. 语气词密度：每3-5句对话至少一个；内心独白可降半档。
2. 每个人物语气词系统固定且与他人区分（口癖是人设的一部分）。
3. 旁白可少量用语气词制造"作者在跟你聊"的亲密感，密度低于对话。
4. 愤怒/激动时语气词消失、感叹号连击：「笨蛋利姆露看不出来吗！！！！」

## 四、句式与段落节奏

### 4.1 短句分镜节奏
动作序列用"动作→结果→反应"三拍推进，每拍独立成段。一段一个动作镜头；镜头内先肢体（主语+动词），再能量/特效，最后补宏观或心理收束句。

```
右手抬起，令维鲁达束手无策的长箭陡然凝滞，一动一静，正如夸大到极致的对比。
小手虚握，抬起的右手猛然下挥，足以撕裂宇宙的力量呼啸奔涌，银光乍现，所有长箭，皆在弹指之间灰飞烟灭。
傲立虚空，眼中毫无感情的色彩，此刻，身穿巫女服的少女就如神明一般，睥睨寰宇。
```

### 4.2 长短搭配
节奏公式：**短句定帧，长句缓释**。激烈处短句连发（2-4段），随后接一个长句把氛围"压住"。禁止通篇同长句（书面腔）或通篇碎片（断片感）。

### 4.3 标志性句式
1. **前置场景句**：主语+动作，环境随之变化。
2. **判断强调句**："这，就是……"
3. **破折号补充句**：主句后跟——+补充。
4. **省略号留白句**：台词或叙述以……收尾制造余韵。
5. **情绪外化句**：内心情绪不直说，用"小动作+环境"呈现（"不断颤动的小手早已暴露主人此刻的内心激荡"）。
6. **作者介入句**：叙述中突然切换口吻（"看吧看吧，我就说，我很看好你的哦"）。

### 4.4 词汇偏好
- 高频动词优先：望、看、落、飞、跃、捏、摸、抚、挥、划、拍、消失、浮现、显出身形、贯穿、席卷、崩解、涌动。
- 高频意象：月光/月色、夜空、星辰、蝠翼、异瞳、魔素、光团、术式、裙摆、指尖、小手。
- 拟声拟态：叮铃铃、咚咚、扑腾扑腾、叮叮咣咣、呜呜、哼哼哼♪。
- 网络语/梗适度使用（每2-3场景一处为上限）：吃瓜、社畜、DNA的恐惧、这单干吗。
- 数字与计量直接摆（"一万八千人""五十公里直径"），增强实感，不解释。

## 五、叙事纪律（视角·场景·节奏·对话·信息·情绪）

### 5.1 总纲铁律
每个新分镜开始前回答三个问题，答不出不动笔：
1. 这是哪类场景？（战斗/对话交锋/日常松弛/心理/景物缓冲）
2. 视角锚点是谁？（跟着谁看）
3. 这段的"爆点"在哪一句？（最高张力句，围绕它铺陈）

### 5.2 场景组织
- **硬切分镜**：换场一律用…………（可附1-2个空格），独占一行；前后允许视觉/空间完全跳跃，读者靠上下文自行接续。
- **开场=定场镜头**：第一二句给出"地点+时间/光照+氛围"之一或组合（"夜晚的森林，犹如深渊般幽邃危险，尤其是在这新月之夜。"）。
- **收场三选一**：①静物意象收束（"树叶因风而动，片刻后，又归于寂静。"）；②命运宣告句（"——法尔姆斯的末日，到来了……"）；③内心独白收束。
- **多线并置**（最核心手法）：同一事件多条战线用…………切成独立短分镜轮流推进；每条线2-6段、各自"行动—结果"闭环；弱线短、强线长、高潮线压轴；切回某线时用一句该线独有状态的复述做接续标记。相隔遥远的两地同时发生也可用分镜交替制造"一切尽在计划中"的共振感。
- **报幕式转场**：视角切换必须有标记（…………View——角色名 / Speaker——角色名）；报幕后第一句立即进入该角色感官。

### 5.3 视角纪律
- 默认第三人称跟随：每个分镜锚定一个镜头角色，其他角色内心不得直接出现。
- 允许的视角形态：①第三人称跟随（默认）；②第一人称切镜（报幕Speaker后，允许吐露偏见与吐槽）；③敌方/旁观者视角——**想写某人很强，让敌人替他害怕**，侧面烘托是抬高主角的标准件；④系统旁白（『告，……』『解，……』），信息投放与节奏变速的合法工具。
- 外→内：先用外部动作呈现，再进内心；禁止"他心里想：……"式直白导入。
- 内心一律用『』直引（主角）或破折号分析段（旁观者），不超过2-3句。
- 旁白人格：允许用——随时插入一两句评价/补充/自问自答；括号旁白必须真的提供信息；插入后立即回到镜头角色。

### 5.4 节奏速度表

| 场景类型 | 节奏 | 段落 | 句长 | 要领 |
|---|---|---|---|---|
| 战斗 | 快 | 极短，大量单句段 | 短句为骨 | 动词驱动、切镜式、能量意象 |
| 对话交锋 | 中快 | 一言一段 | 短促交错 | 抢话、打断、潜台词 |
| 日常松弛 | 慢 | 中长段 | 长短混合 | 允许铺陈细节与闲笔 |
| 心理段落 | 中 | 短 | 短 | 点到即止，2-3句封顶 |
| 景物缓冲 | 慢 | 中长 | 偏长 | 意象服务情绪，不独立铺陈 |
| 高潮爆发 | 极快→骤收 | 极短 | 一句一镜 | 最高张力句单独立段 |

**战斗七工具**：①一句一镜；②动词开头（省略主语）；③技能名/称号输出即画面、不解释原理；④数字倒数增压（"5……4……3……2……1……0，找到你了哦～"）；⑤关键一击放慢成慢镜特写（一慢衬三快）；⑥断句重复（"躲开了——没有——又躲开了"，忌完整排比句）；⑦余波收束（爆炸后接死寂残骸段）。

**张弛交替律**：每两个高强度分镜之间安排一个低强度缓冲段；单场景内部情感高潮后接一小段松弛调侃防滥情；情感重场（死亡、诀别）严禁插科打诨。

### 5.5 对话工艺
- 一言一段，说话人动作紧随其后，回合间无废话铺垫。
- 允许打断与抢话；一回合超三句前必须给角色理由（演讲、威胁、剖白），否则拆散。
- 重要信息不直说，用试探、反问、话里有话推进；旁白用一句破折号点破，不解释超过一句。
- 每句台词（或每两回合）配一个微动作（眯眼、耸肩、把玩物件、移开视线）；动作必须"泄露"真实情绪或塑造性格。
- 禁止裸台词堆叠（连续三回合无动作）、禁止机械式"他说道/她回答"标签滥用；沉默（……）本身就是台词。

### 5.6 信息投放
- 渗透式：世界观附着在行动、战斗、对话、场景物件上带出；单次只投一种设定的一个侧面。
- 破折号补充段：陈述句+——+1-3句补充，结束必须落回动作线；连续3个破折号段=说明文，重写。
- 伏笔纪律：日常段埋（一句话/一物品/一承诺），高潮段收；写下的每个细节都要能在后文产生回响；回收时不给回忆全文，只给1-2句触发记忆的碎片；大伏笔用重复意象（星、丝线、棋子）贯穿。
- 时间快进：单段内压缩数日；报幕倒叙（"将时间拨回到……"）；直接越过低价值时段后文补叙。

### 5.7 情绪渲染
- **微动作外化第一优先**：不写"她很伤心/他非常愤怒"。欢喜=蹭掌心/眯眼/晃小腿；悲伤=攥紧裙摆/泪滴在纸上/说反话；恐惧=颤动的小手/移开视线；心动=捋发梢/搓杯沿/挪半步。一个微动作=一个情绪单位，情绪重场用2-3个递进微动作。
- **道具意象**：月光/烛光/雪/信/纹章是情绪的锚点物件，让道具"替人说话"（烛光熄灭=决心，信上的水晕=眼泪）；景物描写上限2-4句，写完立即回人。
- **情感爆发模板**：铺垫（日常/物件）→触发（一句话/一封信）→情感具象化（微动作+短句）→回忆插叙（1段，用——引导）→振作（行动宣言）；全程10-20段，拖长即滥情。

## 六、五种场景标准动作（速查表）

### 战斗——三拍法
- 蓄力：能量聚集、法阵勾勒、空间扭曲，拉长期待。
- 爆发切镜：3-5个单句段短镜头，动词优先+宏大喻体。
- 余波定格：坑洞、粉尘、死寂或一声感叹，留呼吸。
- 加分项：倒计时、感知加速（"意识被拉出了时间轴"）、以弱胜强的力量反衬。

### 对话——三件套
- 每条对话配三件套之一：动作/表情/一句潜台词心理。
- 一来一回、短促交错，带调侃、潜台词与拆台；对话不解释潜台词，靠后续动作或沉默揭晓。
- 可用思念通话『』开双线：明面对话+心里吐槽并行。

### 日常——锚点+吐槽+甜宠
- 锚点：食物/茶点/小物件（蛋糕、布丁）做场景支点。
- 吐槽：角色互怼+旁白插入，语气词兜底。
- 甜宠微动作点缀：喂食、摸头、rua、蹭掌心。
- 小冲突收场，以…………硬切到下一场。

### 心理——三句式
- 句式一：『』直接引述思考（≤3句，带省略号迟疑）。
- 句式二：一句感受或判断（"心很平静，没有罪恶感"）。
- 句式三：小动作外化（攥紧裙摆、指尖颤动、望向月亮）。
- 整段≤5行；转折用"但""只不过"。

### 景物——两笔勾景
- 一笔光线/色调，一笔动态/气息；第三笔必须落回人物或情绪。
- 出场位置：章首定场、情绪转场、硬切缓冲；每处不超过3行。

## 七、续写作业流程（必走，缺一步视为不合格）

1. **读取前文**：通读待续写部分前后的10-30段；提取：当前视角锚点、在场角色、悬而未决的事项、前文埋过的点（物品/承诺/伏笔）。
2. **识别场景类型**：判定战斗/对话/日常/心理/景物/混合；混合场景明确"骨架类型+穿插类型"。
3. **选定节奏**：按速度表确定段落长度、句长、切镜密度；确定本段最高张力句。
4. **规划分镜**：画出…………分镜序列（含是否多线并置、视角报幕）；每镜一句话概括；确保分镜间有呼应或递进，不是流水账。
5. **按分镜写作**：执行第三~六节；每写完一个分镜，检查是否闭环（有行动有结果）。
6. **收束衔接**：结尾用意象收束/悬念钩子/内心独白之一；给后文留可续写的抓手。
7. **自检**：对照第八节清单逐项过一遍，违反即修改。

## 八、多Agent编排模式（五角色流水线）

单进程写作适合常规续写；当任务为完整章节（≥3000字）、用户要求高质量/精修、或大纲分镜表在场时，启用五角色流水线。使用 Task 工具（subagent_type=general）派发，主进程担任导演与唯一修订者。

### 8.1 五个角色

| 序 | Agent | 职责 | 输入 | 输出 |
|---|---|---|---|---|
| 1 | 导演（Director） | 定场景类型、节奏、视角锚点、爆点句、张弛安排 | 大纲/分镜表/前文 | 导演稿：每镜类型/视角/节奏/段数/最高张力句/硬切点 |
| 2 | 骨干文本（Backbone） | 每镜写骨架句：动作→结果→反应三拍，只含事件与台词，不含修饰 | 导演稿 | 骨干文本（每镜3-10句） |
| 3 | 细节填充（Detail） | 在骨干上填充文气：语气词/微动作/比喻/吐槽旁白/景物两笔/长短句搭配 | 骨干文本 | 初稿正文 |
| 4 | 语言校验（LangCheck） | 语言层：符号系统/错别字勘误/黑名单词/语气词密度/单句段比例 | 初稿正文 | 语言层问题清单+修订建议 |
| 5 | 非语言校验（StructCheck） | 叙事层：视角漂移/分镜闭环/张弛交替/伏笔兑现/爆点句在场/章末钩子 | 初稿正文+导演稿/大纲 | 叙事层问题清单+修订建议 |

### 8.2 编排流程

1. 主进程：接单+锚定文气（读分镜表/前文），产出子任务需要的上下文摘要。
2. 派发【导演】：提示词=大纲/分镜表+前文+本技能第五节（叙事纪律）要点。输出导演稿。
3. 派发【骨干文本】：提示词=导演稿+第四、六节要点（短句分镜节奏/场景标准动作）。输出骨干文本。
4. 派发【细节填充】：提示词=骨干文本+第二、三节（快照卡片/符号语气词系统）。输出初稿正文。
5. **并行**派发【语言校验】与【非语言校验】：同一份初稿、两个角度，同时启动。
6. 主进程汇总：合并两份问题清单→对照第八节自检清单裁决→主进程亲自修订（最小干预）→复检→交付。

### 8.3 串行与并行

- 导演→骨干→细节**串行**（逐层依赖）。
- 语言校验与非语言校验**必须并行**（同一份初稿，两个角度）。
- 短场景（<1000字）或快速档不启用流水线。

### 8.4 子任务提示词模板（主进程按此组装）

```
【导演Agent】
- Skill path: <wudu-novel-writing/SKILL.md 路径>
- Task: 基于以下分镜表/前文<粘贴>，产出导演稿：每镜=类型/视角锚点/节奏/预计段数/
  最高张力句（原文级）/硬切点，遵守张弛交替律与视角纪律（第五节）。
- Save outputs to: <workspace>/director.md

【骨干Agent】
- Task: 基于导演稿<粘贴>，为每镜写骨架句（动作→结果→反应三拍）。
  只写事件与台词原文，禁止修饰语、语气词、比喻、心理渲染。
- Save outputs to: <workspace>/backbone.md

【细节Agent】
- Task: 基于骨干文本<粘贴>，按文风快照卡片填充文气：语气词密度与口癖、
  微动作外化、明喻体系、吐槽旁白、景物两笔、长短句搭配。
  禁止增删事件与台词。
- Save outputs to: <workspace>/draft.md

【语言校验Agent】
- Task: 校验初稿<粘贴>的语言层：①「」『』——…………～（）符号配平与分工；
  ②错别字勘误表（所以→所有/莫约→约莫/绕有兴致→饶有兴致/一幅→一副等）；
  ③黑名单词（无与伦比/然而/非常等）；④语气词密度（每3-5句对话至少1个）；
  ⑤单句段占比≥40%。输出带位置的问题清单+修订建议，不修改正文。
- Save outputs to: <workspace>/langcheck.md

【结构校验Agent】
- Task: 校验初稿<粘贴>的叙事层（对照导演稿<粘贴>）：①视角漂移与报幕缺失；
  ②分镜"行动—结果"闭环；③张弛交替（连续3镜≥4档）；④伏笔埋/收兑现；
  ⑤爆点句是否单独立段在场；⑥章末钩子类型与埋点。输出带位置的问题清单+修订建议，不修改正文。
- Save outputs to: <workspace>/structcheck.md
```

### 8.5 纪律

- 子Agent提示词必须**内嵌所需规则原文**（快照卡片/勘误表/节奏速度表等），不依赖子Agent自行加载skill。
- **阶段边界是防失控的关键**：骨干阶段禁止写文气修饰；细节阶段禁止增删事件；校验Agent只出清单不动正文。
- 主进程是唯一修订者：合并两份清单后亲自修订，修订遵循最小干预，禁止把子Agent建议整段替换。
- 两份校验清单冲突时：语言层与叙事层问题**都修**（不互斥）；同一处被双检同时点名=高置信，优先处理。

## 九、质量自检清单

### 1. 文气符合度
- [ ] 单句段占比≥40%，无连续长段
- [ ] 符号用对：「」「『』」——…………～（）
- [ ] 语气词有密度（呐/嘛/欸/哟/呢/吧/啦/喏），每人口癖固定
- [ ] 旁白有吐槽味，或至少一处自问自答/破折号补充
- [ ] 设定不解释，专名「」直接使用
- [ ] 无长篇心理分析（内心独白≤5行）
- [ ] 景物两笔带过、服务情绪
- [ ] 无黑名单词汇与腔调（第九节）

### 2. 错别字勘误（必做！样本自身错误，产出必须修正）
- [ ] 所以→所有（"所以触碰到的物体"）
- [ ] 莫约→约莫；绕有兴致→饶有兴致
- [ ] 一幅→一副；自做决定→自作决定
- [ ] 对了你来说→对你来说；在是→实在
- [ ] 全文扫描"的地得"与多字漏字

### 3. 字数与结构
- [ ] 达到目标字数（附精确统计）
- [ ] 场景切换全部用…………，无"然后/接下来"生硬过渡
- [ ] 章末有落点（情绪收束或钩子）

### 4. 修订
对未通过项逐条修订，禁止"重写全文"式偷懒；修订后复检再交付（精修模式必做）。

> **校验基准**：对已有正文做对齐/校验时，读取 `references/validation-sample.md`（黄金参照段 + 实测量化基线 + 勘误对照表 + 校验报告模板），按其中流程输出校验报告。量化指标（单句段≥60%、语气词密度、符号分工、违禁词阈值）以该文件实测值为准，本节清单作为快速抽查。

## 十、反例黑名单（绝对避免）

- 大段书面心理分析、说教腔、无递进的三段式排比（情绪性排比最多一组且必须有递进）。
- 文言腔/译著腔：拒绝"之乎者也"与欧化长定语。
- 书面连接词连用成串："然而""与此同时""不仅…而且…"必须稀疏（每千字≤2个）。
- 万能形容词与客观陈述腔：无与伦比、美轮美奂、叹为观止、淋漓尽致、众所周知、需要注意的是、不难看出、总而言之。
- 凑字副词："非常、十分、相当、极其"每千字合计≤2次，优先换精准动词（"极其愤怒"→"怒意烧红了眼"）。
- 感叹号滥用：感叹号只用于爆发时刻（一次场景≤3连发）。
- 场景切换用文字过渡（"镜头一转""话分两头"）。
- 为凑字数写设定说明书或重复已给信息。
- 大段纯世界观说明（>5句不落回行动=说明书）。

## 十一、三档输出模式

| 模式 | 流程 | 适用 |
| --- | --- | --- |
| 快速 | 锚定文气→直接续写/成稿→勘误+字数 | 用户催更、情绪场景直给 |
| 标准 | 锚定→分镜→成稿→轻自检（勘误+字数+卡片抽查3条） | 默认（≥3000字章节可启用第八节五Agent流水线） |
| 精修 | 锚定→分镜→成稿→完整自检→逐条修订→复检，**默认启用第八节五Agent流水线** | 用户要求"检查/精修/保证质量"、重要章节、发布前 |

## 十二、交付格式

1. 正文直接输出（Markdown纯文本，段落即正文）。
2. 文末附【字数：xxxx字】；精修模式附加【修订说明：修正了……】。
3. 若用户只给"写一段战斗"等短场景，单句段占比可放宽，但勘误与文气两条不可省。
