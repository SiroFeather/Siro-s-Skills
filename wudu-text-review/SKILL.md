# 正文校验与修改（雾都文风蒸馏版）

## 〇、一句话定位

> **体检 + 最小干预手术，不是重写。**

对已有的正文做两件事：① 检测——逐条指出它偏离样本文风的位置、类型、严重度与证据；② 修订——按问题类型精准下刀，把正文改回文风轨道，同时让读者看不出"换了作者"。

修订原则：**能改一个字不改一句，能改一句不改一段，能改一段不改全文。** 作者的原意、人名、设定、情节走向、个性化表达（吐槽/梗/旁注）一个都不许丢。

---

## 一、铁律（先于一切，违反即不合格）

1. **先检测后下刀**：动手前先把待检内容逐段对照文风基准（第三节）列出问题清单；没有问题的段落一律不动。
2. **最小干预**：每个问题只做"刚好够"的改动，禁止顺手把没毛病的句子也重写一遍。
3. **只改语言层**：错字、标点、句序、冗余、黑名单词、拆长段、补语气词、微动作外化（若明确偏离）。**绝不碰**：剧情走向、人设性格、设定事实、专名、数字、作者有意为之的梗与双关。
4. **保留作者个性**：吐槽旁注（XDD、P.S.、括号梗）、（喵）规避写法、网络梗、作者自创词、口癖切换（露姆生气换"咱"是语音设计）——全部保留，不许"规范化"。
5. **一次任务只改用户要求的范围**：用户给一段就只改这一段；绝不主动扩大改动面。
6. **拿不准的先问或标存疑**：歧义、双关、疑似故意的错、专有词拼写——标「存疑待确认」，不自行替换。
7. **禁止重写全文式偷懒**：任何段落禁止整体推倒重写；必须逐句定位问题，逐处下刀。
8. **修订必须可解释**：每一处改动都要能说清"为什么"，说不清理由的改动不许做。
9. **评价必须带证据**：每条问题给【位置+原文引用+理由】，不给段号/引文的问题不算问题；"文笔很好"这类无依据评价禁止出现。
10. **交付必带修订说明**：只丢一份改后稿、不给说明，视为不合格。

## 二、接单确认（动检前必答，缺项先问）

| 项 | 内容 | 缺省处理 |
|---|---|---|
| ① 任务类型 | 纯校验（只出报告）/ 校验+修改（报告+修订稿） | 说"检查/看看/打分/体检"→先按纯校验，报告末尾问是否要修订稿；说"修改/帮我改/修一下"→校验+修改 |
| ② 范围 | 全文 / 指定段落（行号、首尾句或场景名） | 全文 |
| ③ 模式 | 快速扫描 / 标准 / 深度精修 | 标准 |
| ④ 修订稿要求 | 要改后全文 / 只要修改建议 | 按③默认 |
| ⑤ 文气基准 | 默认雾都文风；用户另有基准则以其为准 | 默认基准 |

开始前复述接单摘要："校验+修改 / 全文 / 标准模式 / 基准=雾都文风，收到"，用户纠正后再动。

**长文规则**：范围超8000字时先问用户按块拆（每2000-3000字一块），逐块出报告，最后给总报告。短文（<1500字）放宽比例类阈值，勘误与文气两项不放松。

## 三、文气基准速查（检测/修订的参照系）

### 3.1 文风快照卡片（10条）

1. **段落极短**：单句段/半句段为骨（"蓝紫光束，贯穿天空。"），单句段占比≥40%；禁止连续3段以上超4行的长段落。
2. **符号系统**：「」对话与专名；『』内心独白与系统宣告；——插入说明/旁白打断；…………（全角省略号×4，独占一行）场景硬切；（）作者吐槽旁注；～亲昵拖音（旁白叙述中禁用）；……句尾留白。
3. **语气词系统**：呐（最高频）、嘛、欸、哦、哟、呢、吧、啦、喏/诺、的说；对话每3-5句至少一个；同一个人物口癖必须固定。
4. **吐槽役旁白**：作者不隐身——括号插入吐槽、破折号补充设定、旁白自问自答（"至于为什么……自然是有着其特别的用意"）。
5. **设定不解释**：专名/术语用「」包裹直接使用（魔素、术式、究极技能），默认读者懂，禁止说明书。
6. **反差萌主角**：强大到离谱+娇小可爱并存——"小手""小脑袋"做小动作，同时微笑着做恐怖的事。
7. **甜宠微动作**：摸头、蹭掌心、提裙礼、喂食、十指相扣；动词要细；点到即止，不煽情。
8. **心理轻量**：思考优先、『』直接引述（≤3句），辅以小动作外化；禁止大段书面心理分析。
9. **景物服务情绪**：月/光/星空/风是情绪道具，两笔带过（2-4句封顶），第三笔必须落回人物。
10. **明喻体系**：仿佛/宛如/犹如/好像/好似；喻体宏大与生活化混杂（"恍若审判的长矛" vs "像巨人在玩跳绳"）。

### 3.2 黑名单词（出现即记）

- 万能形容词：无与伦比、美轮美奂、叹为观止、淋漓尽致、荡气回肠。
- 客观陈述腔：众所周知、需要注意的是、不难看出、显而易见、总而言之。
- 凑字副词："非常、十分、相当、极其"每千字合计≤2次（优先换精准动词）。
- 书面连接词："然而/与此同时/不仅…而且…"每千字≤2，禁用"镜头一转""话分两头"式文字转场。
- 文言/译著腔：之乎者也、欧化长定语。
- 无递进的三段式排比；感叹号非爆发场景连击（一次场景>3连发）。

### 3.3 样本实测基线（约7008段/19.7万字，供比例类判定参照）

- ≤1个句末标点的段落占比85.9%（合格线≥40%）；≥120字长段仅6个。
- 场景硬切…………162处；破折号——718处；「」2053处 / 『』366处；～129处。
- 语气词丰度：吧264 / 哦118 / 呢94 / 嘛91 / 呐87 / 哟41 / 的说33 / 啦39 / 喏7。
- 基线是参照系不是及格线：全文校验先实测再对照；短文放宽比例类，勘误与文气不可省。

**详细量化基线**（每千字密度、五类场景黄金参照段、判定口径）见 `references/validation-sample.md`——校验前先读黄金参照段让语感对齐，再逐项核对。

## 四、六步工作流（缺一步视为不合格）

### 第1步 读全文，锚定文气
- 通读全文（连标点一起读），**第一遍只读不挑错**。默诵指纹：**短段分镜 × 吐槽旁白 × 二次元设定不解释 × 反差萌 × 甜宠微动作 × 月光意象**。
- 提取基线：场景类型分布、视角锚点、在场角色及各自口癖、语气词密度、单句段占比、黑名单词实测频率。
- 快速模式：读开头+结尾+中间3段采样。

### 第2步 机械扫描（输出"扫描表"：| 规则 | 实测 | 判定 | 位置 |）
1. **符号扫描**：「」与『』各自配平计数；未闭合、错位即记录；嘴说用『』/心想用「」即混用；两段间时间/地点/视角明显跳变却无…………行即违规；～出现在旁白叙述即违规；`…`半角或省略号个数不对即记。
2. **错字勘误**：跑第六节清单；再扫"的地得"误用、多字漏字、叠字错位、未闭合括号。
3. **比例检测**：单句段占比（≥40%）；连续≥3段超4行长段；语气词密度（连续10句对话零语气词=异常）；黑名单词频；感叹号连击。
4. **段落重复**：≥25字段落全文出现≥2次=复制粘贴疑点（注意：短句重复强调是合法手法，不判）。

### 第3步 语感检查（凭感觉，但必须给位置+证据）
- **节奏**：读感快慢是否符合场景类型（战斗快/日常慢/高潮骤收）；哪里卡顿、哪里拖沓。
- **人设**：每个说话角色口癖是否固定、与他人区分；口癖漂移与角色互染一眼可见。
- **文气**：吐槽旁白是否在场（破折号补充/括号旁白/自问自答至少其一）；设定是否不解释直接使用；心理是否轻量（『』直引≤3句）；景物是否两笔带过、服务情绪；情绪重场是否用小动作外化而非直写（"她很伤心"=伪文风高发区）；喻体是否有画面、宏大与生活化混杂、有无堆砌或全文零比喻。
- 禁止空泛结论："这段感觉不对"必须跟"哪一段哪一句，因为……"。

### 第4步 生成问题清单（按严重度排序）
每条问题四要素，缺一不算一条：

| 要素 | 要求 |
|---|---|
| 位置 | 段落号或原文引句，可定位 |
| 类型 | 勘误 / 符号 / 句式 / 语气 / 叙事 / 黑名单 |
| 严重度 | S1致命 / S2严重 / S3中等 / S4轻微 |
| 证据 | 原文引用，一字不改 |

**严重度定义**：
- **S1 致命**：视角混乱；符号系统整体崩坏（对话不用「」、『』「」混用成片）；单句段占比<30%；全文零吐槽（作者隐身）；连续3段以上超4行；≥10行心理分析；说明书段>5句；剧情/人设/设定硬伤（后者**只报告不擅改**，标"待用户确认"）。
- **S2 严重**：错字；黑名单词；长句堆砌成书面腔；连续10句以上零语气词；对话三回合裸堆无动作；情绪重场直写无外化。
- **S3 中等**：节奏失衡；口癖漂移；景物/心理超标；段落过长的单处；喻体堆砌或零比喻。
- **S4 轻微**：可改可不改的润色点、个体风格差异。
- 排序：S1→S2→S3→S4，同级按出现顺序。深度精修模式：清单后附每条修改方案。

### 第5步 修订（最小干预）
- 只有"校验+修改"类任务才执行本步；用户说"只检查"＝零修改，一个标点都不许动。
- 按类下刀（见第七节）；**先修硬伤（错别字/符号），再修结构（长段/景物/说明书），最后修味道（语气词/形容词）**——顺序不可颠倒。
- 改完后把"改前想表达的信息"逐条对回"改后"，确认没有丢失或篡改任何一个信息点。
- 发现大面积问题（整段/整章崩坏）→在报告中写"此段建议重写"并给理由，**等用户确认后才动手**。

### 第6步 复检与交付
- 把修订后文本再跑一遍第2步扫描表，逐条勾销：`已解决 / 保留-待用户确认 / 部分解决`。
- 快速模式抽检3条；标准模式全项扫描表；精修模式全项复检+逐条修订说明核对。
- 组装交付物（第八节报告模板 + 第九节三档模式）。

## 五、错别字勘误清单（机械扫描必做）

### 5.1 样本自带错误（本文风同人稿高频雷区，命中直接标"勘误"）

| 错误 | 正确 | 判定要点 |
|---|---|---|
| 所以触碰到的物体 | 所有触碰到的物体 | 样本原错，仅此语境 |
| 莫约 | 约莫 | "莫约12岁的少年" |
| 绕有兴致 | 饶有兴致 | "绕有兴致的望着" |
| 一幅…的样子/表情/模样 | 一副… | 注意"一幅画"合法，只判"一幅+神态词" |
| 自做决定 | 自作决定 | — |
| 对了你来说 | 对你来说 | — |
| 在是 | 实在 | 需看上下文确认 |
| 迄及 | 企及 | "无法迄及的高度" |
| 排插 | 排查 | "排插机械的故障" |
| 起内部 | 其内部 | — |
| 完全想想不到 | 完全想不到 | 多字重复 |
| 补虫网 | 捕虫网 | — |
| 微不可差 | 微不可察 | — |
| 高兴不以 | 高兴不已 | — |
| 为时以晚 | 为时已晚 | — |
| 一方常态 | 一反常态 | — |
| 沉醉与 | 沉醉于 | — |

### 5.2 的地得快速判定（判不准标"警告勘误"）
- `的`+动词短语→应为`地`（"不断的喘着气"→"不断地喘着气"）；动词+`的`+补语→应为`得`（"跑的好快"→"跑得好快"）；`的`+名词正常、`得`+程度补语正常。
- 漏字/多字/重复字（"或许是是在看不下去了吧"）。

**检测方法**：正则先行（`一幅(?=…样|…表情|…模样)`、`莫约|绕有兴致|排插|迄及`），错字层允许误报，每条人工复核语境后再写进清单。作者刻意玩梗的错字（外号谐音等）不算病，标「建议」不擅改。

## 六、九类修订手法（每类配"改前→改后"示范）

### 6.1 错别字/漏字——直接改，不解释
唯一"不用问作者"的类型。直接改正字，不改句式。

### 6.2 书面腔长段→短句分镜拆分
**手法（三拍法）**：① 找动词轴——圈出长段里真正的行为动词（望/握/迈/停/推/攥），一段只允许一个主角词；② 切成"动作→结果→反应"三拍，每拍独立成段；③ 长句最多留一句做氛围压场，放段尾。

改前：`自己是否应该留下来确认，利姆露现在面对着这样的抉择。一方面，他很担心露姆……另一方面，这个丝线十分蹊跷……究竟是先去找露姆，还是应该查明这些丝线的正体，利姆露自己暂时还没有定论。`

改后：
```
利姆露悬在半空，久久没有动作。
『留下来查明……还是先去找露姆？』
丝线蹊跷，牵涉魔国联邦内部——这是职责。
露姆下落不明，线索就在眼前——这是私心。
『家人，永远排在第一位。』
伸手，将黑魂玉推向露姆的方向，利姆露紧随其后。
```
原意核对：两个选项+最终选择全保留；拆出的单句段之间必须有因果或递进，拆完仍是流水账=失败。

### 6.3 引号符号错位——直引号归「」，内心归『』
- 嘴说→「」；心想/系统通告/精神对话→『』；术语/技能名/称号裸奔补「」。
- 说话人标签（"说道""回答"）能省略就省略，靠段落区分。
- 改前：`露姆在心里想："这小子，居然能看穿咱的计划。"` → 改后：`『这小子，居然能看穿咱的计划呐……』`
- 边界：「」『』分工硬性不可混用；记忆闪回里的对白用『』；括号吐槽原样保留不归一化。

### 6.4 心理分析大段→『』短引+微动作外化
1. 只保留最核心的两句思考转成『』直接引述（带省略号迟疑，≤3句）；2. 其余情绪不写"感"而写"做"——悲伤=攥紧裙摆/别过脸/摩挲空杯沿，恐惧=颤动的小手/移开视线，心动=捋发梢/挪半步；3. 必要的人物背景解释压成——+1句。

改前：`其实露姆是一个很有仪式感的人……也许是她在很小的时候就失去了他人的关爱，所以才会如此惧怕孤独。或许是曾经遭受过刻骨铭心的背叛……`

改后：
```
『有新品要一起试吃——这是说好的约定。』
利姆露忽然想起来，这句话，露姆说过两次。
『所以……连小事都不敢忘记，是因为怕被遗忘吧。』
对面，露姆嘟起小嘴，别过头去。
搭在椅沿的指尖，却悄悄攥紧了。
```
边界：旁观者视角的破折号分析段是本文风特色，允许；连续3个破折号段=说明文，压缩。

### 6.5 语气词缺失/口癖混乱——补语气词，固定人设口癖
1. **对口癖卡**：按人物第一次出场时的口癖统一全场（样本参考：露姆=呐/哦～/哟～/啦，生气换自称"咱"；利姆露=吐槽系+呐/嘛；拉普拉斯=仆卿+啦/哩；迪亚波罗=库呼呼呼+敬语；苍影=无语气词言简意赅；塔琳=喵；盖鲁德=俺）。
2. **补密度**：对话每3-5句至少一个语气词；旁白密度低于对话。
3. **激烈时刻反向操作**：愤怒/崩溃时语气词消失、感叹号连击（「笨蛋利姆露看不出来吗！！！！」）——这是"情绪吞掉口癖"的合法写法，不要补回去。
- 改前：`「我明白了。既然这样，就按你说的做吧。」` → 改后（露姆）：`「明白啦～既然利姆露都这么说了，那就照做吧，呐？」`
- 边界：露姆"咱"自称切换是作者的故意设计（情绪线），检测到"口癖变但不突兀、符合人物状态"时标「建议：疑似有意为之，未改」。

### 6.6 万能形容词/黑名单词→换精准动词或具象画面
1. 删"非常/极其"，把情绪压进具体身体反应或画面；2. 万能形容词用本样本喻体体系（仿佛/宛如/犹如）替代；3. 口语吐槽里天然带的夸张词不在打击范围。
- 改前：`克雷曼的威势无与伦比，利姆露感到极其愤怒。`
- 改后：`怒意烧红了利姆露的金色瞳孔，指尖在刀柄上碾出「咔哒」一声。`
- 纪律：以词换词是偷懒，以画面换词才是修订；修辞一次只能换一处。

### 6.7 景物铺陈过长→砍到2-4句并落回人物
1. 保留"一笔光线/色调+一笔动态/气息"，其余全删；2. 第三笔必须落回人物（动作/视线/情绪）；3. 保留情绪锚点（烛光熄灭=决心的意象要留住）。
- 改前（15行纯诗意铺陈）→ 改后：
```
夕阳的光被无限拉长，新月接替了天幕。
圆桌旁，九位魔王静坐，不动声色。
银辉穿过落地窗，落在利姆露脚边——
他不动声色地，把露姆的椅子又挪近了半寸。
```
- 边界：章首定场镜头允许3行内；战斗余波段（坑洞/死寂）是节奏工具，不动。

### 6.8 场景切换缺硬切符→补…………
- 换场一律补「…………」独占一行；视角切换用报幕式硬切（…………view——角色名 / Speaker——角色名），报幕后第一句立即进入该角色感官；文字过渡直接删。
- 边界：句内"……"是留白不是场景符；只有"单独成段充当分隔符"的省略号才是场景符，必须补满4个全角。

### 6.9 设定说明书式解释→删，或挂到动作/对话上
1. 先删读者能自行理解的部分；2. 必须保留的信息压成一句贴着动作走，或由「智慧之王」用『解，……』『告，……』一句带过；3. 可变成台词里的一句抱怨；4. 单次只留一个侧面。
- 改前（10行原理说明书）→ 改后：
```
「魔法的结界，防得住魔素，可防不住太阳——」
利姆露张开手，头顶的水镜悄然偏转。
「物理攻击，才是结界的天敌。」
光束落下，铠甲在千度高温下化作铁水。
```
- 边界：系统宣告『告，……』是本文风的信息投放工具，不算说明书；连续3条『告』=说明书，压缩成1条。

## 七、校验报告模板（固定结构，逐项填写，不许跳项）

```
# 《校验报告》
## 一、总体评分：X.X / 10 ——【优秀 / 合格 / 需修改 / 不合格】
档位表：
| 档位 | 分数 | 含义 | 处置建议 |
| 优秀 | 9.0-10 | 可直接发布，仅个别S4轻微项 | 可不修订 |
| 合格 | 7.5-8.9 | 小修可发，存在S3及以下问题 | 建议修订 |
| 需修改 | 6.0-7.4 | 存在S2问题或文气明显偏离 | 必须修订 |
| 不合格 | <6.0 | 系统性崩坏（符号/视角/腔调整体偏离） | 建议段落级重写，需用户确认 |

## 二、分维度得分
| 维度 | 得分/10 | 权重 | 一句话诊断（必须带1处证据） |
| 语气 |  | 25% |  |
| 勘误 |  | 25% |  |
| 句式 |  | 20% |  |
| 符号 |  | 15% |  |
| 叙事 |  | 15% |  |
总分 = Σ(维度分 × 权重)，保留一位小数。

评分锚点（各维度通用）：10分=零失误或仅1处S4；6分=问题成批但可单点修复；3分=系统性做错。
勘误特殊规则：错字按个扣分，每1个错字扣1分（含的地得、多字漏字），0错字=10分，下限3分。

## 三、问题清单（按严重度排序）

```

## 八、三档模式表

| 模式 | 报告 | 修订稿 | 逐条修订说明 | 复检 | 适用 |
|---|---|---|---|---|---|

## 九、交付格式（顺序固定）

1. **报告在前**，修订稿在后。
2. 快速扫描只交付报告（用户后续要修订稿再补）。
3. 修订稿为可直接使用的完整正文，正文内**不夹批注**；批注全部进报告的修订说明。
4. 修订稿文末附字数变化：`【字数：原N字 → 改后M字（Δ±K字，±P%）】`。
5. 报告中引用的原文一律用「」或代码块包裹，防止与正文混淆。
